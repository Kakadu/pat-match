Module OCanren.Env

A distinct environment is associated with each OCanren.run. Every fresh variable is associated with an emvironment. Using nested run's with reusing of fresh variables from the previous run will lead to runtime error due to usage of alien environment.

type t
val empty : unit -> t

Creates a new environment. Environment has an internal state: a counter of the variable index introduced last. That's why empty has extra unit argument.

val create : anchor:int -> t
val fresh : scope:OCanren__.Term.Var.scope -> t -> 'a

Creating a fresh variable takes an extra argument scope to decide if storing a substituted value inside a variable is OKay.

The idea was recommended by faster-miniKanren implementation.
